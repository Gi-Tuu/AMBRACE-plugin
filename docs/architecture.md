## 技术栈

- 后端：FastAPI + SQLAlchemy(async) + SQLite + 向量库（本地嵌入模型）+ BM25 混合检索（分词，RRF 融合）
- 前端：Flutter（Android/iOS），状态管理 + Dio + WebSocket + SSE
- 模型：OpenAI 兼容 API（可接入多家大模型服务，BYOK）；本地 OCR/VLM 可选；图片二进制不入推理模型
- 语音：本地 ASR + TTS（SSE 逐句合成、可打断、可降级纯文字）
- 浏览器自动化：可选插件（常驻浏览器上下文预热）；手机感知：无障碍节点树 + 系统级能力（输入/指令）
- 推送：离线推送（编译开关，默认关）；在线时 WebSocket 实时
- 部署：Docker（多架构镜像）/ setup 脚本（Windows / Linux-macOS）；Alembic 数据库迁移

> 说明：以上为通用能力分层概览，具体实现细节与目录路径不在公开版披露。

## 分层概览

后端按职责分层：

- **接入层**：HTTP / WebSocket / SSE 三通道，覆盖对话、角色、记忆、日记、朋友圈、宠物、状态、日程、
  系统、上传、认证、多媒体、隐私、生活、语音、市场、权限、群聊、游戏、MCP、账号、设备、插件等域。
- **认证与权限**：登录鉴权、密码策略、账号体系（主账号 + 受邀子账号）、服务器级/用户级配置管理。
- **数据层**：SQLite + 向量库双通道；数据库迁移版本链；启动时幂等补列兜底。
- **事件层**：进程内事件总线（异步发布/订阅，异常隔离）。
- **业务编排层**：用例编排 + 领域逻辑分离，领域模型内聚。
- **插件框架**：manifest / 注册表 / SDK / 配置扩展点 / zip 安全校验。
- **调度层**：主动交流仲裁、情感关怀、记忆复习、宠物关怀、朋友圈发布、剧情线、日复盘等生成器。
- **服务层**：对话、权限、账号关联、配置解析、推送、语音、联系人、多媒体理解/生成、上传、天气、
  时间线、表情市场、插件桥、功能开关、手机自通知等。
- **工具层**：内置可执行工具（搜索 / 备忘 / 日历 / 图像）。
- **协议层**：MCP（模型上下文协议）客户端管理、多用户隔离、工具适配。
- **记忆域**：统一写入、衰减、去重、抽取、嵌入、BM25 索引、混合检索、评星、可靠性、事实核验、核心/意义记忆、
  Lorebook 触发、摘要、对话过滤、说话人归属、共享事件。
- **多模态域**：织库·全景记忆（卡片生成 / 增量 / 图谱 / 去重）。

前端按领域分层：页面按域分目录（认证 / 首页 / 对话 / 角色 / 社交 / 记忆 / 日记 / 状态 / 织库 / 生活 /
手机 / 设置 / 插件 / 游戏），公共组件、服务层（API 客户端 + 各域 API）、状态管理、数据模型、纯函数工具、
主题 Token 与皮肤、多语种、静态配置。

## 核心数据流

1. **对话（三通道）**：WebSocket 实时双向；SSE 流式（增量打字机 + 块确认 + 收尾，失败自动回退）；
   HTTP 简单请求-响应（可跳过延迟）。共同链路：对话服务 → 认知循环（感知 → 多路召回 → 组装上下文 →
   单次 LLM → 概率反思）→ 回复 + 异步提取记忆/评星/状态评估。
2. **记忆**：双通道存储（结构化 + 向量，双向写关联）；消息触发抽取（印象/偏好/事件/洞察）；补采兜底；
   衰减；AI 自主评星；混合检索；核心记忆/关系锚点/开放循环无条件注入；Lorebook 关键词触发；舞台记忆隔离虚拟内容。
3. **状态**：聊天后异步 LLM 定八维（节流） + 惰性漂移（读时结算，调度器兜底）；世界事实类状态带 TTL 防过期注入。
4. **主动交流**：统一仲裁 tick，事件源 = 随机节律/定时承诺/生日节日/状态触发/情绪关怀/记忆复习/宠物/朋友圈/
   AI 社交/群聊活跃/生活活动完成，经人设统一层生成，WS 推送（离线推送兜底）。
5. **朋友圈**：统一发布（每日上限/间隔）；评论/回复受开关约束；兜底轮询。
6. **手机感知**：无障碍服务采集 → 上报 → 快照 → 对话时注入（新鲜度/长度受限）；查看受隐私上锁约束。
7. **Agent 工具执行**：主链路/搜索/主动行为统一走工具执行器（权限三档 allow/ask/forbid + 生命周期钩子 +
   失败静默降级 + 观测截断）；MCP 工具经适配器并按用户隔离。
8. **群聊游戏**：群消息 `play` 开局 → 引擎（确定性规则，零 LLM）→ AI 玩家经 LLM 决策（仅见自己的局面）→
   WebSocket 实时推送 → 游戏记忆独立表（不污染主记忆）→ 主记忆只存摘要指针。
9. **AI 自主生活（Life Loop）**：周期决策循环（需求→目标→兴趣→活动→生活事件→数字痕迹）；聊天驱动意图；
   回聊缓冲（活动完成后经仲裁门控自然分享）；功能开关控制。
10. **MCP**：连接管理（stdio/SSE/streamable-http，per-server 锁防并发竞态、进程退出清理、超时配置化、
    工作目录按用户隔离）；工具声明注入上下文；资源/提示词只读展示；调用日志；SSRF 防护（禁内网 + DNS 绑定防护）。

## 账号与多租户

- 所有账号默认独立主账号。
- 通过一次性受邀码关联子账号：主账号可关联有限子账号；子账号不能再发码；解除后恢复独立。
- 子账号 API 配置可继承主账号共享配置（密钥脱敏只读）。
- 全局唯一绑定权在主账号。
- 角色可绑定不同 LLM 配置，解析链：任务专用 → 角色绑定 → 用户默认 → 主账号共享默认 → 服务器级 → 环境变量。

## 关键约定

- 数据库时间统一存 UTC（naive），展示时换算本地时区；时间工具集中。
- 数据库迁移走 Alembic 版本链，启动时幂等补列兜底；新增表必须写迁移脚本。
- LLM 调用统一走客户端（用量日志、思考开关、多级配置回退）。
- 工具权限三档（allow/ask/forbid）+ 单工具例外；工具执行统一走执行器，勿绕过直调插件 run_hook。
- 记忆写入统一走记忆服务（双写结构化 + 向量）。
- 角色级开关集中在联动开关；功能开关集中登记。
- 新增 HTTP 路由必须在应用入口显式导入并挂载。
- 事件总线用于模块间解耦，不直接改其他模块内部状态。
- 认知状态标注区分事实/观察/记忆/推断/计划/假设/虚构；推断不是事实，剧情不进常规记忆。
- 多角色知识隔离：共享模型 + 隔离认知空间。
- 文档约定：活跃文档 + 归档；规划台账为唯一权威。
